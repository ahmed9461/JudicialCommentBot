# JudicialCommentBot

بوت تلجرام للبحث عن أحكام قضائية سعودية مناسبة للمقررات القانونية، تنزيل ملف الحكم الأصلي من المصدر، إنشاء تعليق أكاديمي قانوني منظم، ومنع تكرار القضايا المستخدمة.

## الحالة الحالية

تم تنفيذ **المرحلة 1** من المشروع:

- Bot Shell باستخدام aiogram 3.
- صلاحية المالك افتراضياً مع Allowlist لمستخدمين إضافيين عبر Telegram ID.
- أوامر `/allow` و`/deny` و`/users` للمالك.
- أزرار جميع المواد الـ34 من `knowledge/subjects/index.yaml`.
- تحميل وفحص ملفات المعرفة المستقلة لكل مادة.
- SQLite مع migrations داخلية وسجل أولي للقضايا المستخدمة.
- إعدادات عبر متغيرات البيئة وLogging مركزي.
- اختبارات أساسية وGitHub Actions CI.

محرك البحث عن القضايا وتنزيل الـPDF والتقييم والتعليق سيُبنى في المراحل التالية وفق `docs/ROADMAP.md`.

## تشغيل المرحلة الحالية

1. استخدم Python 3.12 أو أحدث.
2. ثبّت المشروع:

   `pip install -e '.[dev]'`

3. انسخ `.env.example` إلى `.env` وضع على الأقل:
   - `TELEGRAM_BOT_TOKEN`
   - `OWNER_TELEGRAM_ID`
4. شغّل:

   `python -m app`

قاعدة البيانات والمجلدات المؤقتة تُنشأ تلقائياً داخل `runtime/`.

## الأوامر

- `/start` — القائمة الرئيسية.
- `/help` — المساعدة.
- `/allow <telegram_id>` — إضافة مستخدم مسموح، للمالك فقط.
- `/deny <telegram_id>` — إزالة مستخدم مسموح، للمالك فقط.
- `/users` — عرض المستخدمين المسموحين، للمالك فقط.

## المبادئ الأساسية

- المالك هو المستخدم الافتراضي، مع إمكانية السماح لمستخدمين إضافيين عبر Telegram ID.
- لكل مقرر قانوني ملف معرفة مستقل وقابل للتعديل.
- أولوية المصادر: وزارة العدل، ديوان المظالم، اللجان والمصادر القضائية الرسمية، ثم Tashree للاكتشاف، ثم مصادر موثوقة أخرى عند الضرورة.
- لا تُعتمد قضية إذا تعذر الحصول على ملف الحكم الأصلي PDF.
- لا يُنشأ PDF بديل من نص الحكم.
- منع التكرار يعتمد على رقم القضية + المحكمة + بصمة SHA-256 للملف، وليس الرابط فقط.
- بعد إرسال PDF وDOCX عبر تلجرام تُحذف الملفات المؤقتة من السيرفر، مع الاحتفاظ ببيانات القضية فقط.
- ملف Word يخضع لفحص نهائي يمنع Markdown أو أي ذكر للذكاء الاصطناعي أو البوت أو DeepSeek.
- توجد إمكانية إعادة توليد التعليق لنفس القضية، أو اختيار قضية أخرى.

## الأمان والإعدادات

الأسرار مثل `TELEGRAM_BOT_TOKEN` و`DEEPSEEK_API_KEY` لا تُحفظ داخل المستودع. استخدم متغيرات البيئة أو ملف `.env` محلي غير متتبع، مع الاعتماد على `.env.example` كمرجع للمتغيرات المطلوبة.
