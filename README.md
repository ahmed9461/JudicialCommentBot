# JudicialCommentBot

بوت Telegram خاص للبحث عن أحكام قضائية سعودية مناسبة للمقررات القانونية، التحقق من ملف الحكم الأصلي، منع تكرار القضايا، ثم إنشاء تعليق أكاديمي عربي بصيغة Word.

## ما ينفذه المشروع

- Owner-only افتراضياً مع Allowlist عبر Telegram ID.
- 34 مادة قانونية، لكل مادة ملف معرفة YAML مستقل وقابل للتعديل.
- البحث عبر DeepSeek مع بحث ويب، مع أولوية للمصادر القضائية الرسمية.
- لا يعتمد أي قضية قبل نجاح تنزيل PDF من مصدر رسمي مع التحقق البنيوي وSHA-256.
- يدعم الحكم الفردي ومجموعات الأحكام الرسمية؛ عند المجموعة تُستخرج صفحات القضية الأصلية ولا يُعاد إنشاء نصها.
- يمنع التكرار عالمياً برقم القضية + المحكمة أو بصمة PDF.
- تقييم نهائي 100 نقطة؛ اختيار تلقائي للقضية القوية جداً وإلا عرض أفضل 3.
- تعليق منظم إلى أربعة محاور وفق نماذج التكليف، مع مصطلحات متكيفة مع المادة.
- DOCX عربي RTL مع فحص نهائي يمنع Markdown وأي إشارات لأدوات التوليد.
- يرسل PDF ثم DOCX في Telegram، ويسجل القضية فقط بعد نجاح الإرسال.
- يحذف ملفات PDF/DOCX المؤقتة بعد الإرسال، مع تنظيف تلقائي للملفات المتروكة.
- زر إعادة توليد التعليق لنفس القضية وزر البحث عن قضية أخرى.
- سجل للمالك عبر `/history` وإدارة المستخدمين عبر `/allow` و`/deny` و`/users`.

## التشغيل السريع

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
# عبّئ TELEGRAM_BOT_TOKEN وOWNER_TELEGRAM_ID وDEEPSEEK_API_KEY
pytest -q
python -m app
```

يمكن التشغيل أيضاً بواسطة Docker Compose أو systemd. راجع `docs/DEPLOYMENT.md`.

## الملفات المهمة

- `docs/PROJECT_MEMORY.md`: ذاكرة المشروع والقرارات الثابتة.
- `docs/WORKFLOW.md`: مسار العمل.
- `docs/SOURCE_POLICY.md`: سياسة المصادر وملفات PDF.
- `docs/STYLE_GUIDE.md`: أسلوب التعليق.
- `docs/VALIDATION_RULES.md`: شروط التحقق قبل الإرسال.
- `knowledge/subjects/`: قاعدة معرفة المواد.
- `config/scoring.yaml`: أوزان التقييم وسياسة الاختيار.
- `config/source_registry.yaml`: المصادر الرسمية ومصادر الاكتشاف.

## الأسرار

لا تضع التوكنات أو مفاتيح API داخل الكود أو Git. `.env` مستبعد من المستودع، و`.env.example` يحتوي أسماء المتغيرات فقط.

## حدود مقصودة

- الأحكام المصورة بالكامل التي لا تحتوي نصاً قابلاً للاستخراج تُستبعد ويبحث النظام عن قضية أخرى بدلاً من استخدام OCR غير موثوق.
- اختبار التكامل الحي مع Telegram وDeepSeek يحتاج مفاتيح المستخدم الحقيقية ولا يعمل داخل CI العام.
- خرائط معرفة المواد تأسيسية وقابلة للتعديل، ويُفضّل مراجعتها دورياً مقابل توصيفات المقررات الرسمية.
