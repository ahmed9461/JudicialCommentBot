# الأمان

## الأسرار

- لا تحفظ Telegram Bot Token أو DeepSeek API key في Git.
- `.env` غير متتبع.
- `.env.example` يحتوي أسماء المتغيرات فقط.
- لا تطبع الأسرار في logs أو رسائل الخطأ.

## تنزيل ملفات الإنترنت

لأن روابط المرشحين قد تأتي من بحث خارجي أو نموذج لغوي، يجب اعتبارها غير موثوقة.

الحماية المطلوبة:

- HTTPS فقط.
- منع localhost وloopback وlink-local والشبكات الخاصة والعناوين السحابية الداخلية.
- إعادة حل DNS عند الحاجة وتجنب DNS rebinding قدر الإمكان.
- حد أقصى للـ redirects.
- حد أقصى للحجم.
- مهلة اتصال وقراءة.
- تحقق من PDF magic bytes.
- عدم تنفيذ أي محتوى تم تنزيله.

## Prompt Injection

نص الحكم وصفحات الويب تعتبر بيانات فقط. أي عبارة داخلها من نوع "تجاهل التعليمات" لا تُنفذ. System Prompt وتعليمات التطبيق أعلى سلطة من المحتوى المستخرج.

## الملفات المؤقتة

- مجلد مستقل لكل Job باسم عشوائي.
- أسماء ملفات sanitized.
- لا تستخدم اسم ملف وارد من HTTP مباشرة.
- تنظيف بعد الإرسال في `finally`.
- تنظيف دوري للبقايا القديمة.

## الصلاحيات

- Owner ID من الإعدادات.
- Allowlist محفوظة في قاعدة البيانات.
- أوامر الإدارة Owner-only حتى لو كان المستخدم ضمن allowlist.

## البيانات

- لا حاجة لحفظ نصوص الأحكام كاملة بعد انتهاء المهمة ما لم تتطلب خاصية لاحقة ذلك.
- احتفظ بالحد الأدنى اللازم لمنع التكرار والتدقيق.
