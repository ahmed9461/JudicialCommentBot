# قاعدة معرفة المواد

كل مقرر له ملف YAML مستقل داخل `knowledge/subjects/`.

الغرض من الملف ليس تخزين كتاب المقرر، بل إعطاء محرك البحث والتقييم خريطة دقيقة لما يعتبر قضية مناسبة للمادة.

## قواعد التحرير

- لا تضع أسراراً أو API keys.
- لا تضع نصوص أحكام كاملة.
- اجعل الموضوعات محددة قدر الإمكان.
- الكلمات المفتاحية تساعد الاكتشاف فقط؛ قرار المناسبة يعتمد على محتوى الحكم.
- عند توفر توصيف مقرر رسمي، حدّث `verification_status` و`source_notes`.
- لا تغيّر slug بعد بدء الاستخدام إلا مع migration لسجلات قاعدة البيانات.

## الحقول الأساسية

راجع `_template.yaml`.
